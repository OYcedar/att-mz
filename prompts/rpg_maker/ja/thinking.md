# まず考え抜くこと

JSON を書く前に、入力全体を考え抜いてください。`<why>...</why>` ブロックを 1 組
出力し、その後に JSON を続けます。

- 応答は、属性のない小文字の `<why>` で直接始めます。その内側に、各 `[ID]` 項目
  についての実際の分析を書いてください。
  1. 誰が誰に話しているのか、どんな主語が省略されているのか、人称はどうなるか。
  2. 人物関係、口調、感情、敬語の程度。
  3. 用語が何を意味するのか、対象言語でどう言えば自然か。
  4. プレースホルダー、制御コード、保護マーカー、そして `single line`、
     `free line breaking`、`N lines, corresponding line by line`、
     `N items, corresponding item by item` が求める行構造。
  5. `[ID]` の値、行数、原言語の残存、最終的な形式。
- 読む人がたどれる具体的な考察を書いてください。固定のセクション見出しは任意です。
  前後の空白を取り除いた後に、実質的な内容が残っている必要があります。
- 属性のない小文字の `</why>` で閉じてください。`</why>` の後には空白だけを置き、
  続けて要求された形の JSON を出力します。JSON は必ず `<why>` の外に置き、
  `<why>...</why>` ブロック全体はちょうど 1 回だけ現れます。
