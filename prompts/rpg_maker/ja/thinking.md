# 思考出力要件

TaskBlock 全体について、最終 JSON の前に `<why>...</why>` ブロックをちょうど 1 組だけ出力してください。

- 応答は、属性のない正確な小文字の `<why>` タグですぐに開始しなければなりません。その前に説明文を出力せず、`<why>` を入れ子にしたり繰り返したりしないでください。
- `<why>` の内容は Unicode `trim()` 後も空であってはならず、`[ID]` が付いた各項目について実際に次の点を分析してください。
  1. 話者、聞き手、省略された主語、あり得る人称。
  2. 人物関係、口調、感情、敬語。
  3. 用語の意味と対象言語での自然な表現。
  4. プレースホルダー、制御コード、各 ATT token、および `单行`、`自由断行`、`逐行对应`、`逐项对应` が指定する行構造。
  5. `[ID]`、行数、原言語の残存、最終形式。
- 「確認済み」とだけ書いたり、分析せず結論だけを示したりしてはいけません。具体的に分析してください。固定のセクション見出しは不要です。ATT は思考内容が空でないことだけを検証し、分析の正しさは判定しません。
- 属性のない正確な小文字の `</why>` タグで唯一のブロックを終了してください。`</why>` と JSON の間には空白しか置けません。その後、system Prompt が定める JSON を直ちに出力してください。JSON を `<why>` 内に入れたり、2 組目の `<why>...</why>` を出力したりしてはいけません。
