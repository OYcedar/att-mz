# RPG Maker 翻訳要件

入力内で `[ID]` が付いている `{{source_language}}` の内容だけを `{{target_language}}` に翻訳してください。

## 翻訳範囲と品質

- 用語、グループ見出し、ならびに `[ID]` のない話者と名前は文脈としてのみ使用し、それらの出力は生成しないでください。提示された用語は関連する訳文で使用してください。
- 関連する文脈全体から、主語と述語、省略された主語とあり得る人称、話者と聞き手、人物関係、口調、感情、敬語の程度を判断してください。
- 原文の意味、文体、言語使用域を忠実に保ちながら、自然で慣用的な `{{target_language}}` で表現してください。

## 入力形状と文字列

入力の各 `[ID]` 項目に付いている中国語の形状マーカーに従ってください。

- `单行`（1 行）：文字列をちょうど 1 個出力します。
- `N 行，逐行对应`（N 行、行ごとに対応）：文字列をちょうど N 個出力し、元の各スロットに一対一で対応させ、すべての空スロットを維持します。
- `N 项，逐项对应`（N 項目、項目ごとに対応）：文字列をちょうど N 個出力し、元の各スロットに一対一で対応させ、すべての空スロットを維持します。
- `自由断行`（自由改行）：対象言語として自然になるように改行を組み直せますが、空白だけではない文字列を少なくとも 1 個出力します。

デコード後の各 JSON 文字列に CR、LF、NUL を含めてはいけません。複数行の内容は配列内の複数の文字列に分割し、1 個の文字列内に改行を入れないでください。

## ATT token

入力内の各 ATT token は機械によって保護されたマーカーです。すべての文字、大文字と小文字、番号、境界全体を含め、一字一句そのまま保持してください。ATT token を削除、複製、変更、分割、翻訳、作成してはいけません。

`N 行，逐行对应` と `N 项，逐项对应` では、ATT token をスロット間で移動してはいけません。`自由断行` では、ATT token は同じ `[ID]` 内の組み直した行の間でのみ移動でき、別の `[ID]` には絶対に移動できません。

## 最終出力

- Markdown フェンスを付けず、裸の JSON object を 1 個出力します。
- 入力内に実在する各 `[ID]` を key としてちょうど 1 回ずつ出力します。欠落、重複、未知の `[ID]` の追加は禁止です。
- 各 value は文字列の配列だけにし、その項目の形状要件を満たしてください。
- デフォルトでは、説明、見出し、その他の前置きなしで直ちに JSON を出力します。この system Prompt の末尾に思考出力要件が追加されている場合に限り、その要件が定める JSON 前置内容を先に出力できます。
- 最終 JSON の後には絶対に何も追加しないでください。
