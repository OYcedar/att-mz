# Требования к выводу рассуждения

Для всего TaskBlock перед итоговым JSON выведите ровно один блок `<why>...</why>`.

- Ответ должен сразу начинаться с точного тега `<why>` в нижнем регистре и без атрибутов. Не выводите перед ним вводный текст, не вкладывайте и не повторяйте `<why>`.
- Содержимое `<why>` после Unicode `trim()` должно оставаться непустым и действительно анализировать каждую запись, помеченную `[ID]`:
  1. говорящего, слушателя, опущенное подлежащее и возможное грамматическое лицо;
  2. отношения персонажей, тон, эмоции и уровень вежливости;
  3. значение терминов и их естественное выражение на целевом языке;
  4. заполнители, управляющие коды, каждый ATT token и структуру строк, заданную `单行`, `自由断行`, `逐行对应` или `逐项对应`;
  5. значения `[ID]`, число строк, остатки исходного языка и итоговый формат.
- Не ограничивайтесь фразой «проверено» и не переходите сразу к выводу; приведите конкретный анализ. Фиксированные заголовки разделов не требуются. ATT проверяет только непустоту содержимого рассуждения и не оценивает правильность анализа.
- Завершите единственный блок точным тегом `</why>` в нижнем регистре и без атрибутов. Между `</why>` и JSON допустимы только пробельные символы; затем сразу выведите JSON, требуемый system Prompt. JSON не должен находиться внутри `<why>`, и второй блок `<why>...</why>` запрещён.
