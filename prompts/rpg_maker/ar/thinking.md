# متطلبات إخراج التفكير

بالنسبة إلى TaskBlock بالكامل، أخرج كتلة `<why>...</why>` واحدة بالضبط قبل JSON النهائي.

- يجب أن تبدأ الاستجابة فورًا بالوسم الدقيق `<why>`، بأحرف صغيرة ومن دون سمات. لا تخرج أي نص تمهيدي قبله، ولا تداخل `<why>` أو تكرره.
- يجب أن يبقى المحتوى داخل `<why>` غير فارغ بعد Unicode `trim()`، وأن يحلل فعليًا كل بند يحمل `[ID]`:
  1. المتحدث والمخاطب والفاعل المحذوف والشخص النحوي المحتمل؛
  2. العلاقات بين الشخصيات والنبرة والعاطفة وصيغ الاحترام؛
  3. معنى المصطلحات والتعبير الطبيعي عنها في اللغة الهدف؛
  4. العناصر النائبة وأكواد التحكم وكل ATT token وبنية الأسطر التي تحددها `单行` أو `自由断行` أو `逐行对应` أو `逐项对应`؛
  5. قيم `[ID]` وعدد الأسطر وبقايا اللغة المصدر والتنسيق النهائي.
- لا تكتف بكتابة «تم التحقق» ولا تنتقل مباشرةً إلى النتيجة؛ بل قدم تحليلاً فعليًا. لا تُفرض عناوين ثابتة للأقسام. لا يتحقق ATT إلا من أن محتوى التفكير غير فارغ، ولا يحكم على صحة التحليل.
- أنهِ الكتلة الوحيدة بالوسم الدقيق `</why>`، بأحرف صغيرة ومن دون سمات. لا يُسمح بين `</why>` وJSON إلا بالمسافات البيضاء؛ ثم أخرج مباشرةً JSON الذي يفرضه system Prompt. يجب ألا يكون JSON داخل `<why>`، ولا يُسمح بكتلة `<why>...</why>` ثانية.
