# まず考え抜くこと

最終的な JSON の前に、まず考えてください。`<why>...</why>` ブロックを 1 組出力し、
その後に JSON を続けます。

- 応答は、属性のない小文字の `<why>` で直接始め、`</why>` で閉じます。このブロックは
  ちょうど 1 回だけ現れます。
- 内側には、各 `[ID]` についての実際の分析を書いてください。文脈、指示対象、人称、
  口調、用語、改行、保護マーカー、原言語の残存、最終的な形式。前後の空白を取り除いた
  後に、実質的な内容が残っている必要があります。
- 「確認済み」とだけ書くのではなく、具体的な考察を示してください。JSON は必ず `<why>`
  の外に置きます。
- `</why>` の後には空白だけを置き、続けて要求された形の JSON を出力します。
