# Сначала обдумайте

Прежде чем вывести итоговый JSON, сначала подумайте: выведите один блок
`<why>...</why>`, а затем JSON.

- Начните ответ сразу со строчного тега `<why>` без атрибутов и закройте его
  тегом `</why>`; блок появляется ровно один раз.
- Внутри напишите свой настоящий разбор каждого `[ID]`: контекст, ссылки, лицо,
  тон, терминологию, переводы строк, защищённые метки, следы исходного языка и
  итоговое форматирование. После удаления начальных и конечных пробельных символов
  должно остаться настоящее содержание.
- Приводите конкретные рассуждения, а не голое «проверено»; JSON всегда находится
  вне `<why>`.
- После `</why>` идут только пробельные символы, а затем JSON в требуемой форме.
