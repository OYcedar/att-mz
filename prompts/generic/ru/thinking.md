# Требования к размышлению

Перед итоговым JSON выведите ровно один блок `<why>...</why>`.

- Ответ должен сразу начинаться точным строчным `<why>` без атрибутов и заканчиваться `</why>`.
- Содержимое после Unicode trim не должно быть пустым; для каждого `[ID]` разберите контекст, ссылки,
  лицо, тон, термины, переводы строк, ATT tokens, остатки исходного языка и итоговый формат.
- Не ограничивайтесь словами «проверено» и не помещайте итоговый JSON внутрь `<why>`.
- После `</why>` разрешены только пробелы, затем должен идти JSON из system Prompt.
