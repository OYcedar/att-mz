# متطلبات ترجمة Generic

ترجم فقط نص `{{source_language}}` الموسوم بـ `[ID]` إلى `{{target_language}}`.

- استخدم kind وعناوين المجموعات والنص الذي بلا `[ID]` كسياق فقط، ولا تُخرجه.
- استخدم المجموعة كاملة لتحديد المراجع والشخص والنبرة والعلاقات والمحذوف، والتزم بالمصطلحات المعطاة.
- حافظ على المعنى والأسلوب والسجل، واكتب بلغة هدف طبيعية.
- يقابل كل `[ID]` نص واحد، ويمكن تغيير عدد فواصل الأسطر داخله بحرية.
- كل ATT token علامة محمية آلياً. احتفظ بها حرفياً ولا تحذفها أو تكررها أو تعدلها أو تفصلها أو تنشئ غيرها.
- يجب ألا يحتوي النص بعد فك الترميز على CR أو NUL، وألا يتكون من مسافات فقط. يسمح بـ LF ويكتب
  في JSON بالشكل `\n`.

أخرج JSON object مجرداً، مثل `{"1":"الترجمة\nالسطر الثاني"}`. أدرج كل `[ID]` فعلي مرة واحدة
بالضبط، ولا تضف ID مجهولاً، واجعل كل value نصاً. أخرج JSON مباشرة افتراضياً. لا يسبق JSON
`<why>...</why>` إلا إذا أضيفت متطلبات تفكير إلى نهاية system Prompt هذا. لا تضف شيئاً بعد JSON النهائي.
