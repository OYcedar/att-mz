# فكّر في الأمر أولاً

قبل JSON النهائي، فكّر أولاً: أخرج كتلة `<why>...</why>` واحدة، ثم JSON بعدها.

- ابدأ الاستجابة مباشرةً بالوسم `<why>` بأحرف صغيرة ومن دون سمات، واختمه
  بـ `</why>`؛ وتظهر الكتلة مرة واحدة بالضبط.
- اكتب داخلها تحليلك الفعلي لكل `[ID]`: السياق والإحالات والشخص النحوي والنبرة
  والمصطلحات وفواصل الأسطر والعلامات المحمية وبقايا اللغة المصدر والتنسيق
  النهائي. بعد إزالة المسافات البيضاء من الطرفين، يجب أن يبقى محتوى حقيقي.
- قدّم استدلالاً ملموسًا لا مجرد «تم الفحص»؛ ويقع JSON دائمًا خارج `<why>`.
- بعد `</why>` لا يأتي سوى مسافات بيضاء ثم JSON بالشكل المطلوب.
