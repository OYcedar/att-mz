# متطلبات إخراج التفكير

قبل JSON النهائي، أخرج كتلة واحدة فقط بالشكل `<why>...</why>`.

- يجب أن تبدأ الإجابة مباشرة بالوسم الدقيق `<why>` بأحرف صغيرة ومن دون سمات، وتنتهي بـ `</why>`.
- يجب ألا يكون المحتوى فارغاً بعد Unicode trim، وأن يحلل لكل `[ID]` السياق والمراجع والشخص والنبرة
  والمصطلحات وفواصل الأسطر وATT tokens وبقايا لغة المصدر والتنسيق النهائي.
- لا تكتف بعبارة «تم الفحص»، ولا تضع JSON النهائي داخل `<why>`.
- بعد `</why>` لا يسمح إلا بالمسافات، ثم JSON الذي يطلبه system Prompt.
