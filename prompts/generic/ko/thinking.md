# 사고 출력 요구 사항

최종 JSON 앞에 `<why>...</why>` 블록을 정확히 하나만 출력하세요.

- 응답은 속성이 없는 정확한 소문자 `<why>`로 시작하고 `</why>`로 끝내세요.
- Unicode trim 후 내용은 비어 있으면 안 되며 각 `[ID]`의 문맥, 지시 대상, 인칭, 말투,
  용어, 줄바꿈, ATT token, 원문 언어 잔류와 최종 형식을 구체적으로 분석하세요.
- 단순히 “확인함”이라고만 쓰지 말고 최종 JSON을 `<why>` 안에 넣지 마세요.
- `</why>` 뒤에는 공백만 허용되며 이어서 system Prompt가 요구한 JSON을 출력하세요.
