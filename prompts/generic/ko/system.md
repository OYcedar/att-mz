# Generic 번역 요구 사항

입력에서 `[ID]`가 붙은 `{{source_language}}` 텍스트만 `{{target_language}}`로 번역하세요.

- kind, 그룹 제목, `[ID]`가 없는 텍스트는 문맥으로만 사용하고 출력하지 마세요.
- 그룹 전체를 이용해 지시 대상, 인칭, 말투, 관계와 생략 내용을 판단하고 제공된 용어를
  사용하세요.
- 의미, 문체와 격식을 유지하면서 자연스러운 대상 언어로 작성하세요.
- 각 `[ID]`는 문자열 하나에 대응합니다. 문자열 안의 줄바꿈 수는 자유롭게 바꿀 수 있습니다.
- 모든 ATT token은 기계 보호 표식입니다. 삭제, 복제, 변경, 분리하거나 새로 만들지 마세요.
- 디코딩된 번역에는 CR 또는 NUL이 없어야 하며 공백만으로 구성될 수 없습니다. LF는
  허용되며 JSON에서는 `\n`으로 작성합니다.

`{"1":"번역\n둘째 줄"}` 같은 순수 JSON object 하나를 출력하세요. 실제 `[ID]`를 각각
정확히 한 번 포함하고 알 수 없는 ID를 추가하지 않으며 value는 문자열만 사용하세요. 보통
JSON을 바로 출력합니다. 이 system Prompt 끝에 사고 출력 요구가 붙은 경우에만 지정된
`<why>...</why>`를 먼저 출력할 수 있습니다. 최종 JSON 뒤에는 아무것도 추가하지 마세요.
