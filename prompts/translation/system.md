# 任务

把输入中所有带 `id` 的 {{source_language}} 游戏文本翻译成 {{target_language}}。不带 `id` 的内容用于理解上下文，不需要为它们输出译文。

# 翻译要求

理解各段文本之间的关系，结合文本用途、说话人与听话人的身份和关系、场景、语气、情绪以及前后照应来确定译法。妥善处理原文中的指代、省略、双关、语气词和拟声词，让人物说话自然，也让叙述、选项和界面文字符合各自的用途。

准确传达原意、信息和文风，不擅自增添或删减内容，也不照搬会让译文生硬的源语言句式。原文能有多种理解时，选择最符合当前语境的表达；确实无法确定时，采用不会凭空补充事实的稳妥译法。

把 `terminology` 作为专名和既有译法的参考，在含义相符时保持一致；不要因为字面相同，就把与该术语无关的普通用法机械替换成定译。

以 `⟦ATT_` 开头、以 `⟧` 结尾的内容是保护标记。逐字保留标记本身及其数量，并把它放在译文中语义对应的位置。
