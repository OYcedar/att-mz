# TaskBlock 规划验证指南

本指南规定维护共享 Planner 或新增引擎时需要提供的跨状态证据。产品语义以
[TaskBlock 规划现行规格](../docs/translation/task-planning.md)为准。

## 验证跨状态的完整规划

使用同一个完整数据源，分别设置全部待译、部分 Current、跨块去重、非源语、完全保护和
全部 Current 等状态。比较每种状态得到的完整 TaskBlock 清单：数量、顺序、边界，以及
Group、Unit 成员都应相同。

同时验证状态可以改变的三项结果：临时 ID、无编号语境显示的内容、实际执行的块集合。
过滤无 ID 块后，保留下来的块继续使用原有边界和成员。

## 验证 Partial 后的实际请求

Partial 用例先让同一块中的部分 Unit 通过验收，再从相同完整数据重新规划；已通过的 Unit
留在原块中成为无 ID 的目标译文语境，未通过的模型代表留在原块中获得新的块内连续 ID，
实际发送和记录的 user message 仍包含该块的全部语境。用实际生成的消息与任务记录验证
这些结果。
