# Generic JSONL 现行规格

输入根内每个普通 `.jsonl` 文件由零行或多行 Group 组成，每条物理行恰好是一个完整 JSON
object：

```json
{"id":"scene-1","kind":"dialogue","units":[{"id":"line-1","text":"こんにちは\n世界"}]}
```

## 1. Group

Group 只允许以下字段：

| 字段 | 要求 |
|---|---|
| `id` | 非空字符串，在整个项目中唯一 |
| `kind` | 非空字符串，由外部操作者定义 |
| `units` | 至少包含一个 Unit 的数组 |

一条物理行是一个完整的语义组，始终整体处理。JSON 中的 `\n` 解码为 `text` 里的 LF，
不会产生新的物理 JSONL 行。

## 2. Unit

Unit 只允许：

| 字段 | 要求 |
|---|---|
| `id` | 非空字符串，在所属 Group 中唯一 |
| `text` | 字符串，是唯一会被翻译的字段 |

`text` 可以为空、只含空白或含 LF；CR 和 NUL 属于无效内容。一个 Unit 的源 `text`
始终对应一个目标 `text`，模型可以自由改变其中 LF 的数量。

ID 和 kind 只拒绝空字符串。纯空白字符串按原值是合法身份，其含义由外部操作者定义。
校验按原值保存身份：区分大小写，不做 trim 或 Unicode 归一化。Group ID、Unit ID 和
kind 是身份而不是文本，不参与翻译。

## 3. 从源格式建立 Group 与文件范围

外部操作者或转换工具先确认每段文本的稳定来源、自然顺序、运行时语境和写回位置，再生成 JSONL：

- **Unit**：保留精确源文与独立写回位置。同一场景内的台词、旁白、姓名和选项可分别写回，仍作为同一 Group 的有序 Unit；多行正文不按显示行机械拆分。
- **Group**：共同提供给模型的完整语境。剧情优先以完整场景或连续对话成组（包含相关旁白、问答、选项及铺垫）；非剧情内容按自身语义归组（如将同一道具或图鉴记录的标题与说明放在同组）。不按目标字符数、固定句数或原格式的数组元素/脚本命令切碎连续剧情，也不将互斥分支或无关记录强行拼接。
- **Semantic Scope（JSONL 文件）**：每个 JSONL 文件是一个 Semantic Scope，保存同一上层来源范围内、按自然顺序排列的完整 Group（TaskBlock 不跨文件组合）。相关 Group 保持在同一文件中；仅在上层来源范围或输出映射不同时才拆分文件。
- **长场景处理**：完整长场景即使超过 Profile 目标字符数也可作为一个 Group 整体发送。仅在所选模型服务的实际输入/输出限制或可复现问题要求缩小任务时，才沿来源自然子段拆分。

Scope → Group → Unit 是 Extract 保存的稳定层次；相同输入重复 Extract 得到相同结构与自然顺序。Survey 模式下，不同所有权决定引用同一 Generic 组名时，`finalize` 按来源自然顺序合并成员并校验来源文件与 `kind` 一致（见[项目调查指南](../guides/translation-project.md#2-调查可见文本)）。

## 4. 严格读取

以下输入会被严格拒绝：

- 重复 JSON key、未知字段或缺少字段；
- 空白物理行（每个物理行都应是一个有效 Group）；
- 无效 UTF-8、无效 JSON，或 `text` 解码后含 CR 或 NUL；
- 重复 Group ID，或一个 Group 内重复 Unit ID；
- 空 ID、空 kind 或空 units。

空输入目录和空 JSONL 文件合法。输入文件可以使用 LF 或 CRLF。ATT 递归读取输入根内、
扩展名精确为小写 `.jsonl` 的普通文件；普通但扩展名不同的文件会被跳过。符号链接、
reparse point、硬链接和其他非普通对象会被拒绝，且不会读取其目标或进入 WriteBack 输出。

自然顺序依次为规范化相对文件路径、文件内行序和 `units` 数组顺序。文件路径只决定任务
与输出位置；Group 身份由 `id` 承担。

## 5. 设计边界

需要更多语境时，把相关源文本放进同一 Group 的有序 Unit。保留每个可独立写回的实际来源
位置，不按相同原文合并 Unit；不同场景和同场景不同轮次的同一句话都可能需要不同译法。自动复用的完整
条件见 [Generic Translate](translation.md#2-相同语境复用)。JSONL 只接受本页定义的字段；
`translate`、`context`、`role`、metadata、格式版本和私有扩展字段均不属于当前契约。

[可执行示例](examples/sample.jsonl)把同一开场场景的对话与选项放进一个完整 Group，另将
独立菜单文字成组，同时展示不同 kind 和多行 `text`。
