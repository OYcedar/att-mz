当前完成边界

Translate 非根业务树

资产读取、译前规划、语言与占位符、模型执行、响应验收、结果 Store 和可信 Lua Host 都已推进到实现层；顶层仍保持 Standard → 可选 Lua 的固定顺序。

只剩真实运行根

停止线是文件、CPU、SQLite 查询/事务、LLM 请求、异步延时、Lua VM 与 SQLite 交互会话等根接口。虚线表示契约存在，但没有生产适配器。

配置全部由外部建立

并发、批量、消息容量、完整 system Markdown、重试延时、语言阈值和 LLM 请求选项都从外部显式注入；模块没有 Default，也不探测硬件自行决定。

仍不是端到端完成

当前没有根适配器和生产组合根，因此不能声称真实游戏已经读取、模型已经请求、译文已经写入或 Lua 已在真实 VM 中执行。
