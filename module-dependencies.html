ATT · 当前实现

一个 CLI，三个独立翻译领域

att mv、att mz 与 att generic 各自拥有完整命令流程和项目数据库。共享模块只提供语义确实相同的能力，不建立统一引擎框架。

领域职责

每个领域保留自己的纵向流程

MV / MZ

理解 RPG Maker 游戏目录、数据文件、事件命令、角色、对话、Rules、修改声明、布局和游戏文件写回。

  • Init 冻结游戏来源并建立项目。
  • Extract 只运行 Builtin 与 Rules。
  • Translate 使用 RPG Maker 分组和字符串数组响应。
  • WriteBack 生成并发布完整游戏候选。
src/rpg_maker/init.rs · extract/ · translate/ · write_back/

Generic

只理解严格 JSONL。外部操作者负责把任意游戏或文本转换为约定格式，并消费译后 JSONL。

  • Init 只保存输入根和语言对。
  • Extract 每次重新读取可变输入，并只清理受影响的 Group。
  • Translate 按文件限制 TaskBlock，按 Group 保留语境。
  • WriteBack 只替换 Current Unit 的 text。
src/generic/ · src/application/generic_command.rs

原子数据库 Lua

每次显式读取一个脚本，在单个 SQLite 事务内灵活修改当前项目数据库；不参与 Extract、Translate 或 WriteBack 阶段编排。

  • ctx.db 执行单条 SQL。
  • ctx.translation 精确修改一个 Unit。
  • 脚本后检查 schema、项目事实、译文不变量与数据库结构。
  • 任一未捕获失败使整个脚本回滚。
src/project_lua/mod.rs · binding.rs · rpg_maker.rs · generic.rs

隔离规则：同一个游戏可以同时建立 RPG Maker 项目和 Generic 项目。两者的数据库、术语、Placeholder、状态、日志、任务记录和输出互不读写。

状态与输出

权威事实停留在所属项目

RPG Maker 项目

<att-dir>/projects/{mv|mz}/name/project.db

保存冻结来源、Builtin/Rules 资产、译文状态、资源和最近 Profile；WriteBack 发布完整游戏目录。

Generic 项目

<att-dir>/projects/generic/name/project.db

保存当前 JSONL 快照、Group、Unit、译文状态、资源和最近 Profile；输出固定在项目 write_back/。

依赖停止线：共享模块不判断当前是哪种引擎，不保存 Generic 去重族，也不解释 RPG Maker 的角色、对话、数组形状、Rules、布局或游戏文件。
