当前完成边界

已实现并有行为测试

除顶层与四个提取模块外，项目记录读取、MZ 文档读取和标准资产 Store 也已有真实 Service。Builtin、Rules 的有界 CPU 工作和文档的有界异步读取均已进入实现。

只剩七个 Extract 根接口

目录解析、文件读取、目录列举、CPU 执行、SQLite 查询、SQLite 事务与可信 Lua Host 尚无生产适配器。上层契约已有实现，不再被误标成“底层未实现”。

尚未生产接线

当前没有组合根把真实 CPU worker、文件系统、SQLite 或 Lua 适配器装入 MzCli。因此不能宣称已经真实建库、读取游戏或执行脚本。

资源选择全部来自外部

文档读取/解析、Builtin/Rules 扫描、Store 编码与批大小都要求显式非零配置且没有默认值；根预算和 SQLite 连接策略留给未来配置边界注入。
