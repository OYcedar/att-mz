# 消息界面现代化与插件适配

仅在满足[主技能的美化触发条件](../SKILL.md#任务范围与美化触发)后读取和执行。
先明确用户要求改变的对象、参考样式和验收效果；已给出方向时沿该方向推进。
本文件提供接入与检查方法，不包含可直接投放所有 VX Ace 游戏的成品插件。

## 从实际消息路径选择接入点

核对 `Game_Message`、`Window_Message`、`Window_ChoiceList` 以及实际姓名、头像、气泡插件，
追踪从事件消息到最终绘字的路径。记录有效的字体、尺寸、加载顺序和覆盖关系，再选择绘制层接入点。
同名类被多次打开时，以最后生效的方法与别名链为准。

保留事件解释器、消息队列、控制码顺序、选择回调和等待语义。改造范围集中在用户要求的消息显示层；
全局修改 `Window_Base` 之前要确认菜单、战斗及其他窗口确实需要同样变化。
参考 MZ 的外观时，在当前 RGSS3 中实现相应绘制与布局；MZ 的
[窗口实现](https://rpgmakerofficial.com/product/mz/rmmz_api/Window.html)采用另一套运行接口。

先确定主要适配关系：

| 游戏中实际存在的行为 | 改造时保留的关系 |
| --- | --- |
| 姓名窗口或姓名 Sprite | 姓名来源、显示一次、定位、层级、隐藏与关闭 |
| 头像或立绘驱动消息 | 实际占位及动态替换，不仅检查事件消息头 |
| 气泡、尾部、位置控制 | 字符锚点、上下左右位置与屏幕边界 |
| 选项帮助 | 最长帮助容量、选项位置及确认／取消后的消息收尾 |
| 自动播放、跳过、隐藏、历史 | 原输入映射、暂停语义和显示状态 |
| 保留窗口或内容复制 | 原边距、复制图元的所有权及释放时机 |

不把某款游戏的实例变量、开关编号、别名或插件方法名当作 RGSS3 标准 API。
发现旧实现与新显示层直接冲突时，按实际职责修正并验证；无关问题不混入美化。

## 姓名与段落的来源

已有姓名解析器时复用其语义。只有正文首行姓名时，结合原文结构、已知姓名来源与真实场景确认，
再把姓名交给姓名牌；不要仅按“首行短”“像人名”或只看译文就删除正文首行。
未知说话人的问号标记也可能是姓名，需按原文结构判断。旁白清空姓名，连续换人及时替换。

若需要额外排版资料，从当前已写回文本及来源映射生成，关联当前文本；译文变化时同步更新。
这类资料只承担确定姓名和段落的显示责任，不替代 ATT 的译文和进度状态。
未匹配到资料的动态消息仍保留原正文与显式换行，不从相邻消息猜姓名或丢弃内容。

区分段落与软换行后，再由实际窗口和字体度量决定折行。布局结果应同时用于绘字、窗口高度与分页，
防止不同阶段分别加缩进、扣头像宽度或套用旧的硬换行规则。

## 统一样式与生命周期

依据用户参考设计正文、姓名牌与相关选项的字体、边距、行距、边框、背景和高亮。
低分辨率画面优先保证字形、对比度与空间层级，不把换皮肤写成提高原生渲染分辨率。

- 姓名牌按文字扩展并限制在可见范围内，与正文的对齐关系明确；顶部消息给姓名牌预留空间。
  气泡与长姓名一起检查，不只测普通底部对白。
- 全套图元随正文同步移动、开合、隐藏、恢复及销毁。消息插件可能在隐藏状态下跳过正常更新；
  需覆盖实际走到的隐藏路径，避免残留姓名牌、背景或可选子窗口。
- 窗口背景、尾部等透明图元连接时避免重叠导致颜色变深；保留原有透明消息的语义。
  采用独立 Sprite 时检查它与原窗口开合、可见性和 viewport 的关系。
- 层级相对于所属窗口稳定设置，避免每帧累加。生成或刷新背景位图的时机与尺寸、样式变化对应；
  逐帧更新通常只处理位置、透明度等状态。
- 使用共享位图时明确借用关系；复制的自有位图在对应副本结束时释放。
  保留窗口复制内容时也复制相关边距，不能仅复制像素后套回旧 padding。
- 字体重置后仍让原来的颜色和启用状态生效。特别检查不可用选项的灰显与禁止确认，
  以及同一消息跨页后的颜色、透明度和阴影。
- 若新增运行时排版，按当前消息或当前组选项帮助计算和缓存，不在每帧重新扫描整库。
  确认缓存生命周期及代表性长消息的开销，再判断是否需要进一步优化。

## 帮助容量与事件等待

新增边距和行距会改变帮助行数与可用高度。根据当前组选项最长帮助，在实际字体和头像状态下计算
所需空间，并与选项、姓名牌一起检查屏幕边界。不能靠裁掉帮助、统一缩短所有正文或跳过选择回调
消除等待。

确认与取消沿用原选择回调，在当前消息实现中清理帮助、暂停、选项和协程状态；
地图传送或剧情继续所依赖的“窗口已关闭／消息不再可见”条件保持完整。
切回普通对白时恢复普通窗口布局，取消后再次打开也不能复用上一次的残留状态。

## 验证本轮改变的使用场景

先用代表性真实材料验证正文完整、姓名只显示一次、行宽及高度正确、控制码次序不变，
再检查实际受影响的消息流程。默认与禁用选项、帮助显示中提前确认、取消后重开、正常翻页、
隐藏恢复、自动播放／跳过和窗口保留各有独立的行为边界，按当前游戏用到的部分覆盖。

可以用中性文本生成不访问桌面的布局预览，说明它验证的是哪些绘图与排版结果。
原生绘制、字体栅格化、真实输入、音视频和剧情效果依照主技能的授权与验收边界处理。
本文件中的适配经验有结构检查和离线消息流程依据，不能作为任意游戏已通过原生实机验证的证明。

交付当前汉化副本、对应源码或可维护的补丁、验证结果、必要基线与恢复方式。
后续翻译写回须保留仍适用的字体与消息修复，并重新生成依赖当前文本的排版资料。
