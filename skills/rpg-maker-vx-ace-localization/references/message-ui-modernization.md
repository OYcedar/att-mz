# 消息界面现代化与插件适配

仅在用户明确要求美化或重做 VX Ace 消息界面时读取和执行。先明确目标样式与改造范围，在当前 RGSS3 中实现绘制与布局。

## 1. 选择绘制层接入点

追踪 `Game_Message`、`Window_Message`、`Window_ChoiceList` 以及活动中姓名、头像、气泡插件的调用与 `alias` 链，以最后生效的方法为准。改造集中在消息显示层，保持事件解释器、消息队列、控制码顺序、选择回调和等待语义不变；除非确认全游戏窗口都需改变，否则不直接全局改写 `Window_Base`。

改造时保留游戏既有的功能关系：

| 既有行为 | 改造时需保持的契约 |
| --- | --- |
| 姓名窗口或 Sprite | 姓名来源、单次显示、定位、层级、隐藏与关闭 |
| 头像或立绘消息 | 实际占位宽度及动态切换 |
| 气泡、尾部、位置控制 | 字符锚点、上下左右位置与屏幕边界 |
| 选项帮助 | 最长帮助容量、选项位置及确认／取消后的状态清理 |
| 自动播放、跳过、隐藏、历史 | 输入映射、暂停语义和显示状态 |

## 2. 姓名分离与段落重排

- **姓名唯一显示**：核对所有姓名入口（独立窗口/Sprite、控制码、正文首行或前缀）。确定姓名牌接管的来源后，停用被替代的旧绘制入口或剥离已被接管的正文前缀，确保说话人姓名只显示一次，同时保留对白中正常的称呼用语。旁白清空姓名，连续换人及时更新。
- **统一折行与缩进**：区分语义段落与软换行，根据实际窗口可用宽度和字体度量统一计算折行、窗口高度与分页。引号对白在最终换行处恢复全角续行缩进（计算断点前先预留缩进宽度，跨硬换行和分页连续跟踪引号闭合状态，闭合后的新段落不继续缩进）。

## 3. 样式、生命周期与帮助容量

- **同步生命周期**：姓名牌、背景和装饰图元随消息窗口同步移动、开合、隐藏、恢复与销毁；覆盖插件自定义的隐藏路径，避免残留图元。
- **位图与性能**：背景位图在尺寸或样式变化时刷新，逐帧更新只处理位置与透明度；自有位图在窗口销毁时释放，排版结果按当前消息缓存，不每帧重算。字体重置后恢复原有的颜色与启用/禁用灰显状态。
- **选项帮助与事件等待**：新增边距和行距后，按当前组选项的最长帮助文本计算所需空间。选择确认或取消时沿用原回调清理帮助、暂停和协程状态，确保地图传送或后续剧情依赖的“窗口已关闭”条件正常满足。
