# RealLive 原生文字与姓名回填

适用于 `Seen.txt`、SEEN 脚本与 `Gameexe.ini` 形式的 RealLive 游戏通过外部适配器接入 Generic 的场景。

## 1. 姓名控制与 `#NAMAE` 配置

- **引号外的姓名控制段**：RealLive 对白前缀 `【姓名键】` 在原生解释器中先作为未引用的姓名控制段解析，随后才进入引号包裹的正文字符串。回填时必须保持 `【姓名键】` 位于 ASCII 引号之外（只给正文加引号），否则姓名会被当成普通正文显示。
- **`#NAMAE` 记录结构**：内部姓名键保持原值，在 `Gameexe.ini` 的 `#NAMAE` 中映射显示译名。修改或新增 `#NAMAE` 行时保留完整的参数段（参数段关联角色语音通道等配置，不可省略或混用其他角色参数）。

## 2. 编码、区域检测与脚本重定位

- **字符映射与原生界面**：确保脚本读取、字宽测量、文本绘制以及动态窗口标题/原生控件的字节到 Unicode 转换使用一致的中文编码映射。
- **启动环境检查**：批量翻译前排查是否存在代码页、系统区域或时区校验，按实际原生条件配置兼容层或字体代理。
- **指令跳转重定位**：译文长度变化时，必须按 SEEN 脚本格式完整重建入口表与全文件跳转偏移，确保控制流与原版一致。
