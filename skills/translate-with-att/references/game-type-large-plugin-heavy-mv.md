# 大型、高插件 RPG Maker MV 翻译经验

## 适用结构与验证范围

适用于具有数万翻译单元、大量活动插件、嵌套插件参数、标准事件文字、自定义数据和多种玩家
界面的 MV 项目。真实项目已经验证静态首次翻译、WriteBack、中文字体应用、正常标题启动和根据
截图定位插件界面漏翻；人工实机复核继续覆盖动态场景、窗口布局、字体回退和剧情分支。

## 调查

- 先读取 Survey 的关系组和少量成员样例，再为已确认来源选择 Builtin、Rules 或 Generic。
- 混合玩家文字与协议值的关系组按成员拆分；其余成员保持自然关系和顺序。
- 截图、场景和触发步骤用于定位活动插件参数、插件源码或自定义数据中的真实消费者。
- 待确认来源保留 `unresolved`，并进入人工实机检查清单。

## Extract

- 游戏路径和目标语言确定后可以在 Survey 审核期间完成 Init；Extract 使用最终所有权与 Rules。
- Extract 后固定完整 Manual，作为术语、Translate 和 QA 的共同语料基线。
- 新增插件来源时更新所有权和 Rules，再重新 Extract，使新增 Unit 进入 ATT 项目状态。

## 术语

- 按章节、地图、角色或剧情 Scope 生成候选，Agent 在完整 Manual 中统一去重、筛选和定译。
- 术语集中于跨大量文本反复出现且容易产生多种译法的专名。

## Translate

- 先沿当前 ATT 状态继续可恢复任务，再把少量剩余条目和语境歧义集中到 Manual。
- 虚拟姓名框按已经确认的外壳定位内部姓名，修订时同时核对正文、原文和控制符。
- Generic 中能够独立理解和写回的记录分别成为 Group，使每个结果都能独立映射回来源。

## QA

- 先阅读按原因聚合的 Review 组，再展开需要处理的自然 ID。
- 对无目标语言文本按语境分类为协议值、文件标记、拟声、专名保留或真实漏译。
- 集中 Manual 后重新导出完整译文，复查术语、控制符、源语言残留和插件界面文本。

## WriteBack

- 使用当前 ATT 状态一次生成完整 WriteBack，并检查输出文件结构和实际差异。
- 插件源码中的 Generic 字面量使用文件、行、原文、引号和唯一命中重新确认写回位置。
- Rules 与 Generic 结果按真实加载顺序合入同一隔离副本，并核对每个来源只有一个译文所有者。

## 字体与封包

- 根据完整当前译文字符集应用中文字体，保留插件和引擎使用的运行时字体名称。
- 封包前检查游戏数据可解析、插件 JavaScript 可解析、存档和原版基线保持原值。
- 把标题、菜单、主要对话、插件界面、换行、裁切和未访问分支列入人工实机复核清单。
