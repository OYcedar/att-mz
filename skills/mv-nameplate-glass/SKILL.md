# 接入 MV 透明胶囊姓名牌

在汉化游戏副本中把人物姓名从正文层级分离，采用 `assets/ATT_NamePlate.js` 的绘制方式显示为宽度自适应的透明胶囊姓名牌，保留当前消息系统的台词、控制符和剧情流程。默认样式使用透明背景、白色细边、白字和深色文字描边；左边缘与对话框对齐，下边缘贴合对话框上沿（顶部消息空间不足时贴合下沿）。

## 调查并选择接入方式

1. 确认目标为 RPG Maker MV，读取 `www/js/plugins.js` 中启用的消息插件及加载顺序。
2. 从真实人物对话追踪到 `Game_Message.add` 和 `Window_Message`，确定姓名由事件文本、转义码、插件字段还是自定义脚本提供。
3. 消息系统已有姓名窗口时，沿用其姓名解析、定位和生命周期并替换绘制样式；只有姓名数据时，复制 `assets/ATT_NamePlate.js` 到汉化副本的 `www/js/plugins/ATT_NamePlate.js` 并在 `plugins.js` 中将其置于目标消息插件之后启用。
4. 在姓名解析处取得说话人姓名交给姓名牌，正文继续交给原消息窗口（旁白使用空姓名）；同步显示、隐藏、定位、关闭和对话回看行为。目标游戏使用 `TS_ADVsystem` 的 `[姓名]正文` 格式时可直接复用随附实现，其余游戏编写对应适配代码。

## 验证交付

- 使用 `node --check` 检查插件语法，核对 `plugins.js` 中的启用状态与加载顺序。
- 核对说话人姓名只显示一次，正文保留原有缩进、换行、语音和控制符。
- 交付汉化副本，并提示任务发起者实机检查普通对话、旁白、连续换人、长姓名、顶部/底部消息、回看及隐藏窗口。
