# 接入 MV 玻璃胶囊姓名牌

目标是在汉化游戏副本中把人物姓名从正文层级分离，使用 `assets/ATT_NamePlate.js` 显示为独立、
宽度自适应的玻璃胶囊姓名牌，并保留当前消息系统的台词、控制符和剧情流程。

## 定位姓名来源

1. 确认目标为 RPG Maker MV，并读取 `www/js/plugins.js` 中实际启用的消息插件及加载顺序。
2. 从一条真实人物对话追踪到 `Game_Message.add` 和 `Window_Message`，确定姓名由事件文本、转义码、
   插件字段还是自定义场景脚本提供。
3. 找到当前拥有姓名解析规则的插件或函数，在该位置把姓名交给
   `$gameMessage.setATTNamePlate(name)`，正文继续交给原消息窗口。
4. 随附插件已经适配 `TS_ADVsystem` 的 `[姓名]正文` 格式；其他消息系统只添加连接当前姓名来源的
   最小适配。

## 写入汉化副本

1. 把 `assets/ATT_NamePlate.js` 复制到汉化副本的 `www/js/plugins/ATT_NamePlate.js`。
2. 在 `www/js/plugins.js` 末尾加入启用项，使姓名牌在当前消息插件之后加载。
3. 使用插件参数设置字体、字号、宽度和位置。`GameFont` 会沿用汉化副本已经配置的中文字体。
4. Skill 使用者结合任务发起者的要求、当前对话框和 `Window.png` 独立确定背景渐变、边框、
   内层高光、文字及文字描边颜色，把实际值写入 `plugins.js`；各颜色字段接受包含透明度的 CSS 颜色值。
5. 让人物对话设置姓名，让旁白使用空姓名；长姓名由插件在屏幕宽度内自动扩展。
6. 把插件与 `plugins.js` 纳入当前汉化副本和最终封包，原版游戏继续作为只读基线。

## 验证交付

- 使用 `node --check` 检查插件语法，并解析 `plugins.js` 确认插件启用且位于消息系统之后。
- 静态核对人物对话只在姓名牌显示姓名，正文保留原有缩进、换行、语音和控制符。
- 向任务发起者交付人工实机检查项：普通人物对话、旁白、连续换人、长姓名、上下位置消息、
  对话回看及隐藏消息窗口。
- 由任务发起者人工启动游戏完成实机验证；根据截图和触发场景调整同一插件参数或姓名连接点。
